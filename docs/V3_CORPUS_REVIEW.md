# Оптимизация документации НГТУ: исходная выборка v2 и кандидат v3

## Исходная точка

Полный обработанный корпус v2 содержит 244 601 чанк из 10 347 источников.
Текущий индекс содержит 10 486 чанков из 842 источников. Локальная исходная
выборка для сравнения — `work/v2/core_relinked.jsonl`. Её SHA-256 совпадает
с полем `source_sha256` в манифесте `work/v2/nntu-kb-v2.tar.gz`:

```text
99d16b84c374de7908f8a6dc49fae8d841f22def78ac7193c991f923cc9d4e50
```

| Категория | v2, чанки | Кандидат v3, чанки |
|---|---:|---:|
| Поступающим | 1 004 | 1 004 |
| Студентам | 1 685 | 1 257 |
| Кампусная жизнь | 1 125 | 1 118 |
| Об университете | 1 984 | 1 949 |
| Нормативные и административные | 4 688 | 4 688 |
| Всего | 10 486 | 10 016 |

В v2 медианная длина чанка 1 399 символов, p95 — 1 747. У 3 007 чанков
выставлен признак OCR, у 1 380 заполнен заголовок раздела. В сохранённых
ответах встречаются посторонние источники: приказ о назначении стипендии
при отчислении, памятка о пособиях при поступлении и страница столовой
при запросе об ЭИОС. Сохранённые отчёты поиска показывают 2/5 для v1 и 4/5
для v2 по попаданию ожидаемого источника в топ-10. Это исходные контрольные
данные, оценка v3 планируется отдельно.

## Первый проход

Разделение по целым документам сохраняет текст, метаданные и соседние связи.
Дополнительный корпус можно использовать для адресного поиска позднее.

| Причина переноса | Документы | Чанки |
|---|---:|---:|
| Приказы о назначении конкретных стипендий за 2024 или 2024/25 | 10 | 202 |
| Три файла расписаний второго семестра 2025/26 | 3 | 152 |
| Анкеты из раздела локальных документов по оценке качества | 18 | 100 |
| Страницы о защитах диссертаций и вакансиях университета | 2 | 16 |
| Всего | 33 | 470 |

Кандидат содержит 10 016 чанков из 809 источников. Из основного поиска
предлагается перенести 4,48% чанков v2. Текущий архив индекса и входные
данные v2 сохранены. Локальная сверка подтвердила, что объединение двух
новых наборов возвращает все исходные записи без изменений, ID не
повторяются между наборами, соседние ссылки остаются взаимными и внутри
документа.

## Что разбирать дальше

- Для правил приёма, перевода, отчисления, общежития и стипендий собрать
  перечень документов с подтверждённой редакцией и областью применения.
  Год в имени файла сам по себе не подтверждает срок действия.
- Проверить сканы приоритетных документов и таблицы по оригиналам.
  В основном кандидате остаются 2 805 чанков с признаком OCR.
- Разобрать 62 чанка со служебными фразами о регистрации изменений или
  ознакомлении. Сначала выделить целые служебные блоки, чтобы не вырезать
  нормативный текст из смешанного чанка.
- Проверить 2 497 чанков с кодом программы и годом в имени файла.
  Сначала подтвердить тип и назначение документа, затем выбирать область поиска.
- На сервере сравнить v2 и v3 при равных настройках по нужному пункту
  в выдаче, его наличию в итоговом контексте и подтверждённости ответа.
  Включить запросы на архивное расписание, анкеты и приказы: для них
  перенос ограничит основной поиск до подключения дополнительного корпуса.

## Воспроизведение

```powershell
python deploy/refine_core_v3.py work/v2/core_relinked.jsonl work/v3_candidate
```

Команда создаёт новый каталог и не перезаписывает существующий. В нём
`core.jsonl` — кандидат, `supplemental.jsonl` — перенесённые записи,
`document_inventory.jsonl` — реестр всех 842 документов с URL, числом чанков
и решением, `report.json` — счётчики, признаки для дальнейшей ревизии и хэши.
`work/` хранится локально. Индексация и проверка ответов на сервере отложены.

## Второй проход: приоритетные документы

После чтения первых чанков и метаданных по основным темам создан
`work/v3_candidate_r2/`. К дополнительному корпусу добавлены два документа,
область действия которых явно ограничена текстом: особенности перевода в
2023 году (7 чанков) и приказ о поддержке получателей социальной стипендии
во время COVID-19 в 2020 году (3 чанка). Итого основной кандидат содержит
**10 006 чанков из 807 источников**, дополнительный — 480 чанков из 35
источников. Предыдущий кандидат оставлен для сравнения.

| Тема и источник | Чанки | Наблюдение по извлечённому тексту | Следующее действие |
|---|---:|---|---|
| Правила приёма 2026/27 | 316 | 2 OCR-чанка, заголовок раздела не заполнен ни у одного чанка. На первой странице явно указан учебный год. | Разметить разделы и проверить таблицы и исключения по оригиналу. |
| Положение о переводе, отчислении и восстановлении | 51 | 2 OCR-чанка, заголовки разделов пусты. Первая страница с реквизитами приказа повреждена OCR; в тексте положения виден код ПВД 11.1/99-21. | Сверить редакцию и реквизиты по оригиналу, затем выделить разделы и пункты. |
| Положение о стипендиальном обеспечении | 25 | 1 OCR-чанк, заголовки разделов пусты. Титульная страница распознана с ошибками; в тексте есть ссылки на акты редакции 2015–2016 годов. | Установить действующую редакцию по оригиналу; не считать дату ссылок сроком действия положения. |
| Страница «Стипендиальное обеспечение» | 11 | Для всех чанков заполнен заголовок раздела. | Сопоставить перечисленные виды стипендий с действующим положением и приказами. |
| Приказ о размерах стипендий 2027 | 4 | Все чанки OCR, реквизиты на первой странице повреждены; текст ссылается на письмо о выплатах с 1 сентября 2026 года. | Сверить размер, дату действия и реквизиты по оригиналу. Имя файла не использовать как доказательство будущего срока действия. |
| «Проживание в общежитии» | 97 | Заголовки разделов пусты, OCR-флагов нет. | Выделить правила, оплату, льготы и сроки; проверить структуру таблиц. |
| Три файла платы за проживание с датой 01.07.20 | 12 | В индексе есть таблицы тарифов, но срок действия из имени файла не установлен. | Проверить оригиналы и наличие более поздних приказов до использования для ответа о текущей цене. |

Ни один из этих документов не исключён только из-за незаполненного
`section_title` или старой даты в названии. На следующем проходе нужны
оригинальные PDF и подтверждение действующих редакций. До этой проверки
логика отбора не должна считать дату в имени файла признаком актуальности.

Повторить второй проход можно командой:

```powershell
python deploy/refine_core_v3.py work/v2/core_relinked.jsonl work/v3_candidate_r2
```

## Третий проход: структура и исключённые категории

В извлечённом тексте трёх PDF сверены переходы между разделами. Команда
`python deploy/review_corpus_v3.py` создаёт `work/v3_candidate_r3/`.
В 104 чанках заполнены поля `section_title` и `section_path`: правила
приёма — 73, положение о переводе и отчислении — 28, положение о
стипендиях — 3. Сверка r2 и r3 подтвердила совпадение ID и остальных
полей. При сборке индекса заголовки войдут в текст для поиска.
Смешанные границы и непроверенные приложения требуют отдельной разметки.
Извлечённый текст служит основанием для навигационной разметки. Сверка
по оригинальным PDF и подтверждение действующих редакций ещё впереди.

Отчёт сопоставляет ID полного корпуса, выборки v2 и r3. Он отличает
исключения v2 от документов, перенесённых в дополнительный набор v3.
При обсуждении возврата важно различать документы, отсутствующие в
основе целиком, и отдельные исключённые чанки сохранённых документов.

Предлагаемый порядок совместного разбора:
1. Категории 01, 02 и 04. Сначала искать пропущенные студенческие
   инструкции, формы и страницы сервисов.
2. Категории 08 и 99. Искать официальные памятки и положения, для которых
   можно определить назначение и редакцию.
3. Категория 03. Выделить каталоги, оглавления и ссылки на пособия.
   Обсудить границу между справкой по программе и поиском по всем РПД.
4. Категории 00, 05, 06 и 07. Рассматривать конкретные документы под
   согласованные сценарии.

Возврат материалов требует совместного решения. Для каждого выбранного
документа сохраняем URL, причину возврата и объём.

## Четвёртый проход: расписание ИЯЭиТФ и два режима поиска

Идентификатор `f3e27a7558459634403242f4` — префикс ID документа
`raspisanie-zanyatij-och-1-semestr.pdf`. Полный v2 содержит 34 чанка
`ocr_prose` со всех 11 страниц. В r3 попали 33 чанка. Восьмисимвольный
фрагмент страницы 9 в этот набор не вошёл. Значения `ocr_confidence`
по страницам лежат в диапазоне 67,9–83,1. Первая страница сохраняет
название института, курс и семестр. В теле страницы OCR смешивает
группы, время и аудитории. Все записи имеют тип обычного OCR-текста,
поэтому соответствие группы, дня и пары нельзя восстановить надёжно
по этим фрагментам. Визуальная сверка PDF и повторный OCR не проводились.

`python deploy/prepare_corpus_v3_search.py` создаёт `work/v3_candidate_r4/`.
В основном файле 9 974 чанка, включая карточку со ссылкой на PDF и
обозначением курса и семестра. Извлечённые OCR-фрагменты расписания из r3
сохранены в `schedule_ocr_review.jsonl` для последующего разбора таблицы.
Дополнительный файл содержит 480 чанков архивных и специальных документов.

Для будущего запуска собрать основной индекс из `v3_candidate_r4/core.jsonl`.
При запуске `chat_web.py` передать его через `--index` и добавить
`--supplemental-chunks /путь/к/v3_candidate_r4/supplemental.jsonl`.
В веб-чате появится выбор «Основная база» или «Архив и специальные
документы». Архив использует BM25 по своему JSONL. Выбор явный, так
можно проверить его по конкретному архивному запросу при запуске на сервере.

## Выдача оригиналов табличных документов

`python deploy/build_file_catalog.py --output work/v3_candidate_r6`
сопоставляет полный корпус v2 с обеими выборками r4. Каталог хранит URL
файла, тип, обнаруженные коды групп, учебные годы и число чанков в каждом
наборе. По записям со статусом `outside` можно найти документы, которых
нет ни в основной, ни в дополнительной выборке. В каталог попадают
официальные ссылки на файлы НГТУ с табличными чанками или распознанным
типом документа. Каталог опирается на имеющиеся данные извлечения.
Таблица, которую прежний конвейер не обнаружил, может потребовать ручного
добавления в каталог.

Для расписаний и учебных графиков поисковый корпус r6 исключает сырые
фрагменты, оставляя их в `raw_table_review.jsonl`. По смешанным документам
сохранён текст для обычных вопросов. Запрос файла по точному имени
доступен для любых записей каталога. По типу поддерживаются расписания
занятий и экзаменов, учебные графики, учебные планы и тарифы общежитий.
При совпадении нескольких файлов чат просит уточнение. При наличии
кода группы и учебного года проверяются оба. Учебный график с 23-САИ
сам по себе не подтверждает наличие расписания пар этой группы.

При развёртывании собрать основной индекс из `work/v3_candidate_r6/core.jsonl`.
Для `deploy/install_chat.sh` указать его в `NNTU_CHAT_INDEX`, каталог
оригиналов в `NNTU_FILE_CATALOG`, а дополнительный JSONL в
`NNTU_SUPPLEMENTAL_CHUNKS`. Чат возвращает ссылку на полный файл НГТУ
и не прогоняет табличное содержимое через генератор для таких запросов.
