# Научные публикации и повторный проход категории 08

Исходный файл `work/v2/chunks.jsonl` содержит 111 689 чанков категории 06
из 4 066 документов. В этой категории смешаны статьи, полные выпуски
журналов, сборники конференций, отзывы на диссертации, программы
кандидатских экзаменов, свидетельства о регистрации ПО и отдельные
студенческие документы, ошибочно отнесённые классификатором к науке.

Скрипт `deploy/expand_research_corpus.py` создаёт комплект на основе r19:

```powershell
python deploy/expand_research_corpus.py --output work/v3_candidate_r22
```

Указать новый путь при повторном запуске. Профили документов определяются
по URL и названию. Для текстового отбора научного содержания используется
текст каждого чанка.

## Правила отбора научного содержания

- Требуются `Ключевые слова:` или `Key words:` и заголовок аннотации
  (`Аннотация`, `Abstract`, `Резюме`) либо DOI/УДК в начале фрагмента.
- До маркера ключевых слов должно быть минимум 100 символов. Размер
  всей выбранной выдержки — от 180 символов. Отдельная строка с
  ключевыми словами не проходит.
- Оглавления, служебные блоки, явно табличные записи и повреждённые
  записи отсеиваются существующими правилами качества. OCR в этот
  отбор научных выдержек не включается.
- Отзывы на диссертации и программы кандидатских экзаменов выделены
  отдельно. В первых хранится экспертная оценка конкретной работы,
  во вторых полезны программы и вопросы экзаменов, а не аннотации статей.
- Текст начинается с заголовка аннотации, если он есть, иначе с начала
  исходного чанка с УДК/DOI. Конец — строка ключевых слов и до двух
  переносов строки со знаком дефиса. Конец основной статьи не копируется.
- Для новой выдержки пересчитываются ID и хэш. Сохраняются исходный
  `source_chunk_id`, URL, страница и кандидаты DOI. Совпадения текста
  с основной базой и внутри добавлений не дублируются.
- Если без явного заголовка аннотации перед ключевыми словами видны
  библиографические ссылки с ` // `, фрагмент направляется на ревизию.
  Незавершённый переносом слова блок в конце чанка также не проходит.

## Полные документы

Научные файлы получают запись каталога с официальным URL и типом
`research_publication`. Полный выпуск журнала и отдельная статья —
разные файлы. Страница аннотации остаётся в чанке, чтобы пользователь
мог найти её внутри большого сборника. Для запроса по теме нужны
семантический поиск по выдержкам и ссылка на первоисточник из результата.
Каталог текущего чата поддерживает выдачу оригинала по точному имени.
Само пополнение каталога не обеспечивает интеллектуальный выбор файла
по любому произвольному научному запросу.

В выборке вручную просмотрены примеры аннотаций о машинном обучении
для экономической безопасности, торможении транспорта, управлении
электроприводами, трансформаторах и энергетике городского транспорта.
Это описания научных работ, которые расширяют тематический поиск.
Они не подтверждают правила или порядок действий студента НГТУ.

## Повторный проход 08

Выбраны 151 дополнительный фрагмент из пяти источников: оформление
практических работ, положение о президентских стипендиях аспирантам,
контроль успеваемости и образовательных отношений ДПО, структура рабочей
программы дисциплины и экспертиза электронных курсов. У последних двух
источников часть сведений адресована организаторам обучения. Их полезность
для реальных студенческих запросов требуется проверить при оценке ответов.
Рекомендации по текущим срокам и требованиям требуют сверки редакций.

`category06_raw.jsonl` хранит всю исходную категорию. `decisions.jsonl`
содержит решение по каждому рассмотренному чанку. `inventory.jsonl`
описывает исходные документы. `added_research_policy.jsonl` содержит
новые фрагменты. `report.json` фиксирует числа и причины отбора.
Прогоны генерации ответов на сервере отложены.

Промежуточный r20 содержал 15 937 записей и более длинные научные выдержки.
При просмотре обнаружены хвосты основной статьи после ключевых слов.
Для r21 граница конца уточнена, поэтому итоговые числа отличаются.

## Итоговый кандидат r22

В основе **15 918 чанков**, прирост к r19 **3 394**: 3 243 научных
выдержки категории 06 и 151 фрагмент категории 08. Каталог содержит
5 625 записей оригиналов. Среди научных кандидатов отсеялось 1 756
точных повторов. Каждая аннотация сохраняет связь с исходным чанком,
страницей и официальным URL. Сверены хэши, уникальность ID, соседние
ссылки и принадлежность финальных выдержек ранее проверенным исходным
срезам. Это проверка целостности. Полная ручная оценка смыслового
качества всех добавлений и серверная оценка ответов ещё впереди.
До ориентира в 20 тысяч остаётся 4 082 текстовых чанка.
