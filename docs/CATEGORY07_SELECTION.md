# Отбор категории 07 и повторная ревизия 04

Исходный файл `work/v2/chunks.jsonl` содержит 20 190 чанков категории 07
из 1 572 документов. Скрипт `deploy/expand_university_corpus.py` группирует
записи по ID документа, определяет профиль по URL и названию и отбирает
фрагменты по содержимому и признакам качества.

```powershell
python deploy/expand_university_corpus.py --output work/v3_candidate_r15
```

Основа r13 содержит 9 837 записей. После отбора в r15 **11 783** записи,
прирост **1 946** из категории 07. Среди новых записей две карточки
официальных справочных таблиц. Каталог оригиналов содержит 1 474 записи.
Скрипты и результаты хранятся локально. Загрузка новых версий отложена
по запросу пользователя.

## Повторный просмотр 04

Дополнительно просмотрены положения студклуба, патриотического клуба,
волонтёрского отряда и конкурсов. Подходящие фрагменты уже есть в основе,
нового текста после проверки ID и точных дублей нет. В подборке также
встречается положение об олимпиаде другого вуза. Из одной категории
нельзя автоматически заключить, что документ относится к студентам НГТУ.

## Содержимое новых фрагментов

- Официальная страница «Образование» даёт 1 076 фрагментов с названиями
  и ссылками на учебные документы. Они полезны для поиска оригиналов.
  Их вклад в ответы о содержании дисциплины ограничен текстом ссылок.
- Страницы обучения аспирантов по ФГОС и ФГТ, знакомство с институтами,
  ресурсы библиотеки расширяют навигацию по университету.
- Устав студенческого профсоюза, пропускной режим и документы подразделений
  добавляют сведения об организации университета. Применимость и редакции
  нужно подтвердить при последующей проверке.
- Справочные таблицы персонала и материального обеспечения содержат
  сложные связи между строками. Для них добавлены карточки со ссылкой
  на официальный раздел. Точность пересказа отдельных записей не оценивалась.

## Правила качества

Используются исходные тексты и URL. Повторы по SHA-256 текста не добавляются.
В r15 отсеклось 881 точное повторение среди потенциальных добавлений.
Пропускаются короткие записи, повреждённые символы, отметки needs_review,
OCR с уверенностью ниже 85, таблицы и служебные блоки. URL исходного
документа и страница сохраняются. Новые цепочки соседей идут только
между добавляемыми фрагментами того же документа. Сверены ID, хэши и
взаимность соседних ссылок по всему корпусу r15. Прогоны ответов на
сервере ещё впереди.

`category07_raw.jsonl` хранит исходную категорию, `university_inventory.jsonl`
— назначения документов, `university_decisions.jsonl` — решение для каждого
рассмотренного чанка, `added_university.jsonl` — новые тексты и карточки.
`report.json` фиксирует объём и причины отбора.

До 20 тысяч текстовых записей остаётся 8 217. Каталог файлов учитывается
отдельно. Резерв ручной ревизии 07 составляет 2 313 исходных чанков,
часть которых может оказаться повторами или содержать ошибки. Для
дальнейшего общего роста потребуется отбор разделов категории 03 и
студенческих нормативных документов категории 08. Повторная нарезка
уже сохранённых фрагментов не увеличит тематическое покрытие.
