# Проверка оставшихся категорий 99 и 00

Из полного `work/v2/chunks.jsonl` выделены 20 012 чанков категории 99
из 757 документов и семь записей категории 00 из семи источников.
Категория 05 пропущена по запросу пользователя. Все остальные категории
полного корпуса проходили предыдущие отдельные этапы ревизии.

Воспроизводимый прогон:

```powershell
python deploy/review_unclassified_corpus.py --output work/v3_candidate_r23
```

Скрипт берёт основу r22 и проверяет ID и точные совпадения текста перед
добавлением. Для повторного запуска требуется новое имя выходного каталога.

| Назначение | Исходные чанки | Документы |
|---|---:|---:|
| Научные публикации и выпуски журналов | 10 476 | 271 |
| Библиотечные материалы и выставки | 3 129 | 181 |
| Неопределённые оригиналы | 1 752 | 206 |
| Кадровые, закупочные и служебные материалы | 1 738 | 15 |
| Отчёты | 1 399 | 17 |
| Пособия | 839 | 9 |
| Общие нормативные акты | 625 | 10 |
| Диссертационные материалы | 28 | 26 |
| Карьерные предложения с периодом | 19 | 15 |
| Изображения категории 00 | 7 | 7 |
| Формы | 4 | 4 |
| Датированные тарифные таблицы | 3 | 3 |

Научные документы распознаются по пути журналов или DOI с признаками
аннотации. Применены правила предыдущего отбора 06: ключевые слова,
аннотация либо DOI/УДК, достаточная длина содержательного текста,
читаемый текст, отсутствие смеси с библиографией и незавершённых переносов.
Добавлены **255 выдержек из 137 источников**. Ещё 271 потенциальное
добавление совпало с уже имеющимся текстом. Основной корпус вырос с
15 918 до **16 173 чанков**. Каталог вырос с 5 625 до **6 139 записей**.

Обнаружены полезные оригиналы, которые раньше скрывались в категории 99:

- `posob2.pdf`, `posob3.pdf`, `posob6.pdf`, `posob7.pdf`, `posob8.doc`,
  `posob9.doc` — радиационная и инженерная обстановка, чрезвычайные
  ситуации, устойчивость объектов. Это учебные материалы с расчётами.
- `rukovodstvo_k_resheniy_zadach_po_teorii_veroyatnosti_i_mat_statistike.pdf`
  — руководство по решению задач по теории вероятностей и математической
  статистике, 205 исходных чанков.
- Пособия по инновационной экономике и управлению инновационными
  процессами. В примерах видны ошибки извлечения, поэтому сохранены
  ссылки на полный PDF.

Запись в каталоге позволяет открыть файл по точному имени. Полноценный
выбор таких пособий по произвольной теме ещё требует описательных карточек
с подтверждёнными названиями, дисциплинами и авторами. Нахождение пособий
по чрезвычайным ситуациям не подтверждает их принадлежность конкретной
кафедре БЖД.

Категория 00 включает изображения с рекомендациями по выбору профессии,
фотографии мероприятий и плакаты. Часть OCR-текста сильно повреждена.
В текстовую основу записи 00 не добавлены.

Для 1 752 чанков назначение остаётся недостаточно определённым. Выборка
с seed 23 показала старое областное постановление, повреждённый скан,
распоряжение об огнетушителях, состав диссертационного совета и благодарность
школы. Автоматический профиль сохраняет их для следующего решения.

Просмотрены примеры новых научных выдержек и всех девяти пособий по
первым фрагментам. Сверены уникальность ID, хэши текста и взаимность
соседних ссылок всего r23. Полная ручная ревизия смыслового качества,
проверка актуальности документов и серверные прогоны ответов впереди.

В r23 сохранены `category99_raw.jsonl`, `category00_raw.jsonl`, полный
реестр `inventory.jsonl`, решения `decisions.jsonl`, новые выдержки
`added_unclassified.jsonl`, основной корпус и каталог оригиналов.
До ориентира 20 000 остаётся 3 827 текстовых чанков.
