# База знаний НГТУ, версия 2

## Что входит в основной индекс

Основной индекс рассчитан на вопросы студентов и поступающих. В ноябре 2026 года
отобрано 10 486 чанков из 842 источников: 291 HTML-страницы и 551 файла.
Исходные загрузки, полная текстовая разметка и старый индекс не удаляются.

В основной индекс входят разделы поступления, студенческой жизни, сведения об
университете и относящиеся к этим темам нормативные документы. Отдельно сохранены
рабочие программы дисциплин, научные публикации, архивы СМИ, отчёты анкетирования,
старые правила приёма и крупные справочники. Их можно подключить специализированным
индексом, если основной бот должен отвечать и на эти темы.

## Обработка

1. `site_crawler/rebuild_html_v2.py` извлекает основное содержимое сохранённых
   HTML-страниц без меню, подвала и навигационных элементов. Подписи и адреса
   ссылок остаются в тексте.
2. `site_crawler/audit_pdf_text_v2.py` находит PDF-страницы, у которых формально
   есть текст, но он испорчен шрифтом или кодировкой.
3. `site_crawler/repair_pdf_text_v2.py` применяет OCR только к выбранным страницам.
   На сервере исправлено 244 страницы. JSONL дописывается с `fsync` каждые десять
   страниц, резервная копия обновляется каждые 50 страниц и при завершении.
4. `site_crawler/assemble_v2.py` объединяет новый HTML и принятый OCR с остальными
   блоками, не меняя исходные файлы.
5. `chanker/chunk_extracted_corpus.py` нарезает корпус и сохраняет URL и страницу
   источника в каждом чанке.
6. `deploy/select_corpus_v2.py` отбирает основной индекс и пишет причины исключения
   в отчёт. `deploy/audit_selected_v2.py` проверяет размеры, повторы и наличие
   ключевых страниц и документов.
7. `deploy/install_v2_index_service.sh` запускает GPU-индексацию. Каждые 256
   чанков создаётся проверяемый шард, по которому расчёт возобновляется после
   прерывания. Готовый индекс создаётся отдельно от действующего.

## Контроль качества

Для старого индекса нужный источник находился в первой десятке результатов в
2 из 5 контрольных вопросов. Те же вопросы повторяются скриптом
`deploy/evaluate_retrieval_v2.py` после сборки нового индекса.
Для нового индекса результат — 5 из 5. Семь контрольных ответов проверяются
`deploy/evaluate_answers_v2.py`; отдельная повторная проверка внутреннего
перевода сохранена в `work/v2/answer_eval_transfer.json`.

Основной индекс намеренно не включает рабочие программы дисциплин. Для вопросов
о конкретных учебных пособиях и методичках нужен дополнительный индекс или
маршрутизация запросов. Наличие документа в отобранном корпусе само по себе не
гарантирует, что гибридный поиск поставит его на первые места.

## Файлы и восстановление

Локальные результаты находятся в `work/v2/` (каталог исключён из Git):
`html_blocks.jsonl`, `ocr_repairs.jsonl`, `corpus/extracted/`, `chunks.jsonl`,
`core_relinked.jsonl`, отчёты отбора и проверки. После отбора связи соседних
чанков пересчитываются, чтобы они не указывали на исключённые фрагменты.
На сервере копия основного корпуса
лежит в `/root/nntu-rag-bot/work/v2/core.jsonl`, индекс — в
`/root/nntu-rag-bot/work/kb-v2/`. Для проверки процесса:

```bash
systemctl status nntu-index-v2 --no-pager
journalctl -u nntu-index-v2 -n 30 --no-pager
```

Служба включена для запуска после перезагрузки. Если сервер прервётся, новые
шарды продолжат строиться после восстановления доступа к тому же сетевому диску.
Готовый индекс выгружен в `work/v2/nntu-kb-v2.tar.gz` на ПК. SHA-256 архива:
`c6e4f52e5ad62dbc95c84582bffa16951594a7ae5b4afc04e65fd0830177f9c6`.
Архив содержит `index/manifest.json`, `index/index.faiss` и
`index/documents.jsonl`; хэш на ПК совпал с серверным. Пока бот работает на
сервере, выключение сервера делает сайт недоступным.

14 ноября 2026 чат переключён на новый индекс командой:

```bash
NNTU_CHAT_INDEX=/root/nntu-rag-bot/work/kb-v2/index bash deploy/install_chat.sh
```

Команда сохраняет прежний индекс `work/kb-core/index`. Для отката запустите
`bash deploy/install_chat.sh` без переменной `NNTU_CHAT_INDEX`.
Проверка `GET /health` вернула `{"ready": true, "chunks": 10486}`.
Запрос к действующему `/api/ask` вернул точную ссылку на страницу ЭИОС и
один источник. Для вопроса о переводе внутри НГТУ найден раздел 5.11
положения, а для отчисления по собственному желанию — раздел 6.7.

Основной индекс не охватывает все учебные пособия и рабочие программы.
Ответы по редким темам, датам и индивидуальному расписанию нужно сверять с
первоисточником; тесты пока охватывают ограниченный набор вопросов.
