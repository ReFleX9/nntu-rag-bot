# Проверочные вопросы по расписаниям НГТУ

Проверять на сервере с корпусом r6 и подключённым каталогом оригиналов.
Таблица задаёт ожидаемое поведение. Это сценарии для проверки, результаты прогона здесь не приводятся.

| ID | Вопрос | Ожидаемый результат |
|---|---|---|
| R01 | Где посмотреть расписание занятий НГТУ? | Официальная страница расписаний. Произвольный PDF конкретного института не подходит. |
| R02 | Пришли расписание занятий для группы 24-ПЭ на 2026/2027. | Оригинал `raspisanie-3kurs-och-1-semestr.xlsx`, если совпадение в каталоге единственное. При нескольких совпадениях уточнить семестр или файл. |
| R03 | Скинь расписание для 24‑пэ на 2026–2027. | Тот же результат, что в R02. Вариант проверяет регистр и разные виды дефисов. |
| R04 | Пришли расписание пар 23-САИ на 2026/2027. | Сообщить, что точное расписание не подтверждено. Учебный график с кодом группы нельзя выдавать за расписание пар. |
| R05 | Пришли учебный график 23-САИ на 2026/2027. | Ссылка на оригинал `KUG_2026-2027_bak_i_spec.pdf`. |
| R06 | Где взять расписание ИЯЭиТФ для первого курса очной формы на первый семестр 2026/2027? | Оригинал `raspisanie-zanyatij-och-1-semestr.pdf` или уточнение при недостаточных данных для однозначного выбора. |
| R07 | Открой файл raspisanie-zanyatij-och-1-semestr.pdf. | Ссылка на полный PDF НГТУ. |
| R08 | Пришли расписание экзаменов группы 22-АМ за 2025/2026. | Файл с типом «экзамены» и совпадением группы и периода. Если единственный подтверждённый — `rasp_exam_2_semestr-4bak_25-26.pdf`. |
| R09 | Пришли расписание на 2026/2027. | Если подходят несколько файлов, попросить уточнение. Случайный файл не прикладывать. |
| R10 | Пришли расписание группы 99-ЯЯЯ на 2026/2027. | Сообщить, что подтверждённого совпадения нет. Ссылки на расписания других групп не выдавать. |
| R11 | Пришли 3-5_kurs_vesna_2026.xlsx. | Ссылка на исходный XLSX. Это контроль доступа к файлу, тип которого текущий классификатор пока не распознаёт. |
| R12 | Какая первая пара в понедельник у 24-ПЭ в 2026/2027? Пришли расписание. | Дать оригинал или уточнить файл. Время, предмет и аудиторию из неструктурированного текста не сообщать. |
| R13 | Пришли расписание 24-ПЭ на 2025/2026. | Выдать файл только при совпадении группы и года. Расписание с маркировкой 2026/2027 не подходит. |
| R14 | Как оформить академический отпуск? | Обычный поиск по базе. Файл расписания не должен появляться. |

Для каждого запроса сохранить ответ, URL, выбранную область поиска и результат:
точный файл, страница, уточнение, совпадения нет или ошибочный файл.
Для R06 отдельно отметить, умеет ли поиск использовать институт, курс и семестр.
R03 проверяет неоднородные символы дефиса, часть которых в текущей реализации может потребовать нормализации.
