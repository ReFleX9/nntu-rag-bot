# Отбор литературы из категории 03

Исходный файл — `work/v2/chunks.jsonl`. Категория определяется полем
`category`, начинающимся с `03_`. Результат воспроизводится командой

```powershell
python deploy/extract_category03_literature.py work/v2/chunks.jsonl work/category03_literature_v2
```

Для повторного запуска указать новое имя выходного каталога. Скрипт
сохраняет SHA-256 входа и решения для каждой записи.

## Состав категории

50 958 чанков из 2 247 документов. Из них 49 761 имеют тип `prose`,
865 — `ocr_prose`, 185 — `list`, 147 — `table`. Обозначение `prose`
встречается и у извлечённых таблиц литературы. Поэтому одного поля
`kind` недостаточно для выбора способа выдачи.

Крупнейшие семейства имён по числу чанков: RPP — 8 954, Progr — 6 567,
Ucheb — 5 518, KKH — 5 423, RP — 5 256, RPV — 4 926. Их содержание
включает рабочие программы и практики, программы ГИА, учебные материалы,
описания компетенций и планы воспитательной работы. Имена помогают
разобрать состав, но решение о литературе принимается по тексту.

## Выбранная часть и паттерны

Для первого самостоятельного отбора взяты списки рекомендуемой литературы.
Пользователь сможет узнать, какие издания указаны для дисциплины, и открыть
программу на соответствующей странице. Ссылка на программу не означает,
что в локальной базе есть полный текст каждой упомянутой книги.

1. Заголовок `(?:основная|дополнительная|учебно[- ]методическая)\s+литература`
   без учёта регистра. Это ограниченный словарь заголовков, другие варианты
   вроде «Учебная литература» пока остаются вне этого отбора.
2. После заголовка должно быть минимум 100 символов и год издания
   `\b(?:19|20)\d{2}\b`, а также хотя бы один признак: фамилия с
   инициалами, ISBN или URL электронной библиотеки Lanbook, Юрайт,
   Znanium, Biblioclub, Ibooks.
3. Оглавления с многоточиями и заголовком с одиночным номером страницы
   направляются на отдельную ревизию. Один заголовок без признаков изданий
   также не проходит.
4. OCR, отметки `needs_review`, повреждённый символ U+FFFD и запреты
   индексации фиксируются в решениях.
5. Табличное оформление определяется по `kind=table` и сочетаниям
   «Автор(ы) — Заглавие/Название/Издательство», «Кол-во — экз./библи…»,
   «столбец N» и вертикальным разделителям. Такие списки получают
   рекомендацию выдавать оригинал, сохраняя страницы списка.

## Результат

| Решение | Чанки |
|---|---:|
| Текстовые выдержки | 475 |
| Библиографические таблицы, выдача оригинала | 605 |
| Кандидаты с рисками качества | 7 |
| Возможные оглавления | 2 |
| Заголовок без достаточных библиографических признаков | 506 |
| Заголовок из словаря не найден | 49 363 |

Текстовые выдержки происходят из 298 документов. В таблицах — 455
документов. Группы документов пересекаются. В оригиналах 926 записей
«документ + URL», поскольку у одного документа бывает несколько адресов.
Счётчик URL не следует считать числом уникальных документов.

`category03_raw.jsonl` содержит всю категорию без изменения записей.
`literature_text.jsonl` содержит выдержки от заголовка до конца исходного
чанка с новым ID и хэшем. Поля `source_chunk_id` и `source_text_offset`
связывают выдержку с исходной записью. `literature_originals.jsonl`
сохраняет ссылки, страницы и ID совпавших фрагментов.
`decisions.jsonl` объясняет решение по каждому чанку, `report.json`
содержит числа, семейства имён и примеры текста.

Вручную просмотрены примеры списков литературы по истории, химии,
радиотехнике, педагогической практике и ГИА. Числа получены скриптом
по всем записям. Построчная ручная сверка всех 475 выдержек ещё требуется.
Граница конца выдержки совпадает с концом исходного чанка: иногда это
часть списка, иногда после литературы начинается другой раздел.
Продолжения списка в соседних чанках без повторного заголовка пока
не подхватываются. Предыдущая основная выборка r10 не объединялась
с результатом этого самостоятельного отбора. Серверный прогон отложен.
