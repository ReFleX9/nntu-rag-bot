# Выборочная ревизия категорий за пределами 01–03

Просмотрены исходные фрагменты документов из текущего корпуса r10 и реестра
исключений. Для обзора использована случайная выборка с seed 19: до шести
документов из каждой представленной в основе категории и до пяти из каждой
исключённой категории. Дополнительно найдены документы по ключевым студенческим
сценариям. Категория 05 исключена из этой ревизии по запросу пользователя.
Таблица описывает назначение источников. Проверка действующих редакций впереди.

Ограничение базы категориями 01–03 уберёт из текстового поиска источники
по академическому отпуску, индивидуальным планам, переводу и отчислению,
поддержке студентов с инвалидностью, контактам и вакантным местам.
Категория отражает способ сортировки, а назначение документа следует
определять по содержимому и вопросам пользователей.

Для следующего прохода предлагаем сохранить 04, 07 и 08 как источники
конкретных студенческих процедур и услуг. В 06 и 99 рассматривать отдельные
файлы для каталога оригиналов или повторной классификации. Пример стажировки
или тарифа с датой следует показывать с периодом, указанным в источнике.
Численную оценку полезной доли по такой выборке получить нельзя.
