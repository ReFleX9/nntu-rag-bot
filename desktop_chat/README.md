# Локальное приложение «Чат НГТУ»

Ярлык на рабочем столе запускает `launcher.py` через `pythonw.exe`.
Окно загрузки показывает время запуска; после загрузки базы открывается
отдельное окно Edge без адресной строки. Код доступа подставляется автоматически.
Закрытие окна Edge останавливает принадлежащие приложению процессы
сайта, Ollama и дочерних вычислителей. При закрытии во время ответа
незавершённый ответ теряется; сохранённый индекс не изменяется.

Настройки именно этого ПК находятся в игнорируемом файле
`work/desktop_chat.json`: пути к Python, моделям, индексу и браузеру.
Сайт слушает только `127.0.0.1:18080`, отдельная Ollama —
`127.0.0.1:11435`. Приложение не включает автозапуск Windows.

Используется отдельный профиль Edge `work/desktop_edge_profile`, чтобы
обычные браузерные окна пользователя не определяли время жизни чата.
Повторный запуск ярлыка при уже работающем приложении показывает сообщение.
Журналы: `work/desktop_server.log`, `work/desktop_ollama.log`,
`work/desktop_browser.log`.

Для работы нужны файлы в текущем рабочем дереве проекта и модели по путям
из конфигурации. Не удаляйте рабочее дерево, пока пользуетесь ярлыком.
