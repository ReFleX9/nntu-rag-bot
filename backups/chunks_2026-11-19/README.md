# Резервная копия корпусов и индексов

Архивы хранятся через Git LFS. После клонирования выполнить

```bash
git lfs pull
```

Проверенная исходная версия кода развёрнутого v2 — commit `c8b48ec`.
В архиве `v2.tar.gz` находятся полный корпус, варианты отбора, отчёты,
OCR-артефакты и архив `nntu-kb-v2.tar.gz` с готовым индексом.
`core_relinked.jsonl` соответствует полю source_sha256 манифеста индекса:

```text
99d16b84c374de7908f8a6dc49fae8d841f22def78ac7193c991f923cc9d4e50
```

Архив исходного готового индекса v2:

```text
c6e4f52e5ad62dbc95c84582bffa16951594a7ae5b4afc04e65fd0830177f9c6
```

Для восстановления v2 распаковать `v2.tar.gz` в `work/v2/`, затем
`work/v2/nntu-kb-v2.tar.gz` в отдельный каталог. Внутри будет `index/`.
Индекс подключается существующим способом через `NNTU_CHAT_INDEX`.
Проверить SHA-256 извлечённых файлов по `manifest.json` этой копии.
Код кандидатов требует отдельной серверной оценки перед переключением.

Остальные архивы соответствуют одноимённым каталогам `work/`, включая
промежуточные r1–r10 и варианты отбора литературы категории 03.
`nntu-index.tar.gz` — дополнительная копия старого локального архива индекса.
Модели, Python-окружение и реквизиты сервера нужно восстановить отдельно.
Оригиналы PDF доступны в локальной загрузке и по URL источников.

`manifest.json` перечисляет исходный путь, архив, имя внутри архива,
размер и SHA-256 каждой сохранённой записи.
