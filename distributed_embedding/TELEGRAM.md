# Управление расчётом через Telegram (Windows)

`telegram_control.py` сам запускает один worker и остаётся включённым для
приёма команд. Одновременно второй worker для той же части не запускайте.
Разрешён только личный чат с Telegram ID владельца. Другие чаты игнорируются.
Используется long polling Telegram Bot API: открывать порт на роутере не нужно.

1. Создайте отдельного бота через официальный `@BotFather` в Telegram,
   получите токен и отправьте новому боту `/start` со своего аккаунта.
2. Узнайте числовой ID своего аккаунта. Это ID пользователя, не username и
   не ID группы. Укажите его в `NNTU_TELEGRAM_USER_ID`.
3. Запустите PowerShell из корня репозитория с установленными зависимостями
   для вычислений. Секрет вводится скрыто и действует только в текущем сеансе:

```powershell
$secret = Read-Host 'Токен Telegram-бота от BotFather' -AsSecureString
$env:NNTU_TELEGRAM_TOKEN = [System.Net.NetworkCredential]::new('', $secret).Password
$env:NNTU_TELEGRAM_USER_ID = Read-Host 'Числовой Telegram ID владельца'
$env:USE_TF='0'
$env:USE_FLAX='0'
python distributed_embedding/telegram_control.py --part 0 --device cpu --batch-size 4 --model-dir 'C:\Users\lisit\OneDrive\Desktop\rag_gazprom\vendor\nntu-models\qwen3-embedding-0.6b' --out work/two_pc_part0
```

В этом проекте библиотеки основного ПК сохранены в `vendor/nntu-deps`.
Если используете их вместо виртуального окружения, перед запуском задайте:

```powershell
$env:PYTHONPATH='C:\Users\lisit\OneDrive\Desktop\rag_gazprom\vendor\nntu-deps'
```

Для ноутбука укажите `--part 1`, путь к его копии модели, `--device auto`
и отдельную выходную папку `work/two_pc_part1`. Для одновременного управления
двумя ПК нужны два отдельных Telegram-бота: один токен нельзя использовать
двумя polling-процессами одновременно.

## Кнопки

- **Прогресс**: число записанных чанков, процент этой половины корпуса,
  состояние процесса и последние строки `worker.log`. Промежуточная работа
  внутри шарда не считается сохранённой; шард содержит до 256 чанков.
- **Сохранить порцию и выключить**: подтверждение действительно 120 секунд.
  После подтверждения текущий шард досчитывается и записывается, процесс
  выходит с кодом 42. Бот проверяет хэши всех сохранённых файлов, порядок
  чанков и число/размерность/нормализацию векторов. Ожидание шарда на CPU
  может занять более часа.
- **Выключить после проверки результата**: после подтверждения разрешение
  действует до конца текущего запуска. Когда эта половина корпуса успешно
  рассчитана, проверяются шарды, собранный индекс и метаданные `two_pc_job.json`.
  Присутствие второй половины с ноутбука не требуется.
- **Отменить выключение**: снимает выбранный режим и запрос остановки.
  Если worker уже завершился, повторный запуск выполняется вручную.

После успешной проверки бот сообщает о выключении и ждёт 120 секунд;
в это время можно нажать отмену. Подтверждение режима заранее разрешает
автоматическое выключение, без дополнительного вопроса в конце расчёта.
При ошибке расчёта или проверки ПК остаётся включённым. Проверка файлов
проверяет целостность индекса, качество ответов LLM она не оценивает.

Команда Windows выполняется без принудительного закрытия приложений.
Приложения с несохранёнными документами могут задержать выключение.
Бот не выполняет произвольные команды и не предоставляет доступ к файлам.

Пока supervisor работает, он препятствует автоматическому сну Windows;
экран может выключаться. Держите окно PowerShell открытым, ноутбук — на
питании. Закрытие крышки, ручной сон и перезагрузка могут остановить процесс.
Интернет нужен для Telegram. Во время отсутствия связи расчёт продолжается;
команды будут обработаны после восстановления связи. Ошибки Telegram
выводятся без адреса запроса, чтобы не раскрыть токен в журнале.

Чтобы продолжить после досрочной остановки, удалите `stop.request` из
выходной папки и повторите команду. Сохранённые шарды будут проверены и
пропущены. Настройка выключения не переносится на следующий запуск.

Исходники и инструкции подготовлены; подключение к реальному Telegram и
фактическое выключение требуют настройки владельцем и пробного запуска
до отъезда. Реальные токены и файлы с ними не сохраняйте в репозитории.
