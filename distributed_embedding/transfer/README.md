# Перенос вычисленных шардов и сборка индекса

Здесь опубликованы `part0_complete.zip` (первая часть, 8086 векторов,
включая готовый индекс) и `part1_remaining.zip` (шарды 5–31 второй части,
6807 векторов). `archives.sha256.json` фиксирует контрольные суммы архивов.

На другом ПК остаются первые пять шардов второй части — `shard_00000`–
`shard_00004` (1280 векторов). Они **не входят** в эти архивы. Не удаляйте
папку `work/two_pc_part1` на том ПК до успешной сборки.

Клонируйте репозиторий вместе с Git LFS (`git lfs pull`), установите
`rag_hybrid_langchain/rag_hybrid/requirements.txt` и запустите из корня:

```powershell
python distributed_embedding/transfer/assemble.py `
  --other-part1 work/two_pc_part1 `
  --model-dir C:\path\to\qwen3-embedding-0.6b
```

Если папка с первыми пятью шардами находится не в `work/two_pc_part1`,
укажите её полный путь. В ней нужны также `job.json` и все три файла
каждого шарда: `index.faiss`, `documents.jsonl`, `manifest.json`.

Скрипт проверяет SHA архивов, одинаковость исходного корпуса и параметров
эмбеддинга, хэши модели, а затем штатный worker проверяет каждый шард
и собирает индекс второй части. Последний шаг объединяет обе части
в `work/assembled_r23/index` — 16173 вектора. Исходные архивы и шарды
остаются на месте.
