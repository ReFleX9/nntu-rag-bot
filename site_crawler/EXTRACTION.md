# Извлечение корпуса НГТУ

`extract_corpus.py` собирает текст из скачанных файлов (`files.jsonl`) и HTML
страниц (`pages.jsonl`) в `data/nntu_site/extracted/`. Исходники остаются в
`data/nntu_site/files/` и `data/nntu_site/pages/`.

## Запуск

```powershell
python site_crawler/extract_corpus.py data/nntu_site
```

Для продолжения после остановки:

```powershell
python site_crawler/extract_corpus.py data/nntu_site --resume
```

Проверить подмножество можно с `--limit N` или `--only часть-имени-файла`.
OCR по умолчанию работает на 150 dpi; параметр `--dpi` меняет разрешение,
`--no-ocr` отключает его. Прерванный файл будет повторён при `--resume`,
завершённые файлы повторно не извлекаются.
Ошибочные документы можно повторить с `--retry-errors`, а статус `empty` —
перепроверить с `--reprocess-empty`.

## Формат выходных данных

- `blocks.jsonl`: текстовые блоки с `doc_id`, источниками, категорией и
  привязкой к странице PDF, абзацу/таблице, листу Excel, слайду или HTML.
- `documents.jsonl`: статус обработки, SHA-256, тип, число блоков/страниц,
  объём текста и OCR-страниц.
- `errors.jsonl`: файлы, которые не удалось обработать.
- `report.json`: сводные счётчики по типу, категории и статусу.

PDF извлекается сначала как native text. Tesseract включается только для
малотекстовых страниц с изображением на странице; страницы рендерятся MuPDF,
а Tesseract обрабатывает до четырёх страниц параллельно. Текстовые страницы
не проходят OCR. Для OCR сохраняются оценка уверенности и dpi; до шести
страниц параллельно обрабатываются отдельными процессами Tesseract.

HTML блоки включают подписи и адреса гиперссылок, чтобы бот мог показать,
куда перейти. Старые бинарные `.doc` и `.ppt` требуют отдельной конвертации;
они отмечаются в `errors.jsonl`, если подходящего конвертера нет. Современные
DOCX/XLSX/XLS/PPTX, RTF, XML/CSV/TXT и крупные изображения поддержаны.
ZIP-контейнеры не распаковываются автоматически: их нужно отдельно проверить
на состав и безопасно обработать вложенные документы.

Зависимости Python перечислены в `requirements-extraction.txt`. Tesseract
должен быть установлен отдельно; в этой рабочей копии его двоичные файлы и
модели лежат в игнорируемой Git папке `vendor/`.

После завершения извлечения можно уточнить слабые/неопределённые категории по
началу извлечённого текста и пересобрать ссылочную витрину (без копирования
данных):

```powershell
python site_crawler/refine_classification.py data/nntu_site --rebuild-view
```

Свести повторы от повторных запусков и проверить качество можно командами:

```powershell
python site_crawler/deduplicate_extraction.py data/nntu_site
python site_crawler/audit_extraction.py data/nntu_site
```
